# Project Proposal Feedback

The project is clearly described and well motivated, and the fallback plan of switching to an over/under or yes/no classification is a thoughtful way to manage risk. The goals would be stronger with measurable criteria. State the metrics you will use (for example MAE and RMSE for minutes, and F1 or ROC-AUC for the fallback classification) and the baselines you must beat, such as a player's season average or last-5-game average minutes. The primary goal's wording ("changing from regular season to playoff games") is unclear, so say whether you will train separate models or include playoffs as a feature, and note that playoff data will be much smaller. The secondary goal lists "propaganda surrounding a player," which is not measurable, so either define it with a concrete feature or remove it. The 80/20 train-test split should be chronological rather than random, since a random split lets future games leak into training, and all rolling averages must use only prior games. Also avoid using same-game stats (points, rebounds, assists) or other players' minutes in that game as features, since they are not known before tip-off. Consider adding game context features such as the point spread, since blowouts strongly affect minutes. The data plan should name and link specific sources, list the seasons you will cover, and explain where historical injury designations and coach data will come from, including how you will respect scraping limits for Basketball-Reference. The timeline is reasonable in structure but vague, and the Week 8 entry is cut off, so please complete it. Finally, proofread for small typos!
